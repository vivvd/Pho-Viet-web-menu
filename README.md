# Pho Viet — меню

Локальное меню на React/Vinext: 48 блюд, 7 категорий, выбор вариантов и список для официанта. Заказы никуда не отправляются.

## Запуск

Требуется Node.js 22.13+ и зависимости проекта.

```sh
npm install
npm run dev -- --port 4173
```

Открыть http://localhost:4173. Для меню на другом устройстве потребуется отдельно настроить доступный ему адрес; localhost относится к тому устройству, где открыт браузер.

## Данные

- `lib/menu.json` — исходные блюда и цены из архива.
- `lib/order.ts` — варианты, правила гарниров, валидация сохранённого списка и расчёт в копейках.
- `public/images` — 48 оригинальных lossless WebP.

Пюре, фри, рис и макароны включены в цену всех блюд «с гарниром». У наггетсов фри фиксирован. Максимальное количество одной комбинации — 99. Список хранится в localStorage под ключом `pho-viet-list-v1`; при запрете хранилища работает в памяти текущей страницы.

## Проверки

```sh
npm test
npx tsc --noEmit
npx oxlint app lib/order.ts tests/order.test.cjs
npm run build
```

Полный `npm run lint` также проверяет неиспользуемые компоненты исходного шаблона; в них остаются исходные замечания. Проверка кода меню проходит отдельно.

Результаты ручных браузерных проверок — в `QA.md`.
